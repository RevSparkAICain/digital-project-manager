## Rules

- Use only the colors above. Primary marks titles, key numbers and one focal element per page or slide; accents mark secondary series and highlights.
- Body text uses the text color on the background color. White text sits only on the primary color.
- Charts take the chart series in order and keep that order across related charts.
- Start decks from the starter `.pptx` and documents from the starter `.docx` when they exist.
- Status colors (red, amber, green) are a functional cue only and stay off brand elements.
