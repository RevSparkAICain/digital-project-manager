# Jargon Swaps

The house list of technical terms and the plain wording your organization uses for them in
messages to staff. The left column is the term as IT writes it; the right column is what
goes in front of the reader. When a rollout turns up a new term, add a row.

How to use a row: replace the wording, and keep what it means. If the plain version drops
something the reader actually needs, keep the technical term and explain it once, inside
the same sentence.

Each row names a kind of technology, never a product. If the reader will see a product
name on screen, add it in parentheses after the plain wording.

## Accounts and sign-in

| Technical | Plain |
|---|---|
| Multi-factor authentication (MFA) | An extra check after your password, most often approving a prompt on your phone |
| Single sign-on (SSO) | One sign-in that opens your other work apps too |
| Onboarding and offboarding access | Giving people access when they start or change roles, and taking it away when they leave |
| Idle session lockout | After a stretch with no activity, the app asks you to sign in again |
| Password manager | A secure app that stores your passwords so you do not have to remember them |

## Devices and network

| Technical | Plain |
|---|---|
| Endpoint | Your work computer or laptop |
| Mobile device management (MDM) | Settings that IT puts on your work phone for you |
| Configuration profile | A bundle of settings your computer receives without you doing anything |
| Remote access client | The app you open first when you work away from the office |
| Security update | A fix your computer installs so a known problem cannot be used against it |
| Exploitable flaw | A gap in the software that an attacker could get through |
| Clear the browser cache | Make the browser forget saved pages so the site loads again from scratch |

## Data and applications

| Technical | Plain |
|---|---|
| Enterprise resource planning (ERP) system | The central system for orders, stock and the accounts |
| Optical character recognition (OCR) | You take a photo and the app types out the words for you |
| Cloud file storage | Your files live online rather than only on your own computer |
| Sync client | Keeps one up-to-date version of your files on each device you use |
| Point-in-time restore | Getting a file back as it was at an earlier moment |
| Data loss prevention (DLP) | Checks that catch private information before it is sent out by accident |
| Personal data | Details that identify a customer or a colleague |
| Encryption | Information is scrambled so only the right people and systems can read it |
| Integration | Two systems pass information to each other on their own |
| Cutover | The moment you stop using the old system and start using the new one |
| Test environment | A practice copy, kept apart from the one people work in |
| User acceptance testing (UAT) | Staff from the business try the new version before everyone gets it |
| End of support | After a set date the old version gets no more fixes |
| Latency | How long you wait for a response |
| Maintenance window | The hours when the system is switched off for work |
| Rollback plan | How we return to the old version if the new one fails |
| Changelog | The record of what is new or different in this version |

## Process and governance

| Technical | Plain |
|---|---|
| Change advisory board (CAB) | The group that signs off on a change before it goes ahead |
| Major incident | A serious failure or attack that a team is fixing right now |
| Root cause analysis | Working out why a failure happened so it does not happen again |
| Service level agreement (SLA) | How fast we have promised to respond |
| Self-service portal | The site where you ask IT for things and follow your requests |
| Risk register | The tracked list of things that could go wrong and who owns each one |
| Approval chain | The people who must say yes before a request goes ahead |

## Phrases to drop entirely

| Do not write | Write instead |
|---|---|
| "All users must..." | "You need to..." |
| "Unlock new functionality" | "You can now [action]" |
| "No major disruption anticipated" | The actual cost, such as "about [number] seconds", or "Your day stays the same" |
| "Kindly note that" | Cut it and open with the fact |
| "In line with our continued focus on..." | Cut it and open with the change |
| "Industry-leading platform" | Say what the platform does |
| "Smooth migration" | Say what happens and what stays the same |
| "Contact IT with any questions" | Give the one queue, article or person |
| "Over the next few weeks" | The calendar date |
| "Strengthened security" | Name what is now protected |
| "Retire the legacy system" | "The old [system] stops working on [date]" |
| "Enable staff to..." | "You can now..." |
